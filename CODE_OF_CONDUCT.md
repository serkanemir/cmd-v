# Code of Conduct

cmd-v is a small open source project. The goal is to keep discussion practical, respectful, and safe for contributors and users.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept correction when something lands poorly.
- Keep issues and pull requests focused on cmd-v.
- Report security concerns through the security reporting path instead of posting exploit details publicly.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Deliberately derailing issues or pull requests.
- Posting sensitive security details in public issues before a fix is available.

## Enforcement

The maintainer may edit, hide, lock, or delete comments and may block users who violate this code of conduct. Enforcement decisions are made to protect the project and its contributors.
